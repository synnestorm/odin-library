# Odin Project: Library

In this assignment I were to create a small Library app. Here you can add and remove books, toggle read/not read.

## Built with

- JavaScript
- HTML5
- CSS3

## Getting Started

### Installing

1. Clone the repo:

```bash
git clone git@github.com:synnestorm/odin-library.git
```

2. Install the dependencies:

```
npm install
```

### Running

To run the app, run the following commands:

```bash
npm run start
```
